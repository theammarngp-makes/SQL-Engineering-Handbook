## What's Covered

- A shared, seeded schema (`00_Sample_Schema.sql`) so every lesson
  runs against consistent, verifiable data
- A consistent structure across every lesson: business context,
  engineering notes, diagrams, dialect differences, common mistakes,
  and interview questions with answers
- Two deliberate, worked production-bug examples — an absorbing
  `ELSE` branch (Lesson 04) and a surrogate-key classification rule
  (Lesson 05) — shown broken, explained, and fixed
- Advanced patterns (Lesson 06) and end-to-end business case studies
  (Lesson 07) beyond basic syntax
- A consolidated interview-prep bank (Lesson 08)
- All SQL verified to run correctly against the seed schema, with
  documented expected output matching actual results
- Original SVG diagrams and a hero banner for the README and each
  lesson file, under `assets/`

## Diagrams & Visual Assets

All SVG assets in `assets/` (banner, ERD, and per-lesson diagrams)
are flat, dependency-free SVG so they render natively in GitHub's
markdown viewer with no external tooling required.
